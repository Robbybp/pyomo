Advanced Capabilities
=====================

The :ref:`tutorial<pynumero-tutorial>` section contains examples of using the
basic functionality of PyNumero. PyNumero also contains some advanced features
that may be useful for specialized applications in the domain of nonlinear
optimization.

.. warning::
   These advanced capabilities of PyNumero are less mature than the basic features
   described in the :ref:`tutorial<pynumero-tutorial>` (which themselves are less
   mature than the core Pyomo codebase). APIs and functionality of these features
   may change without wraning. See :ref:`pynumero-backward-compatibility` for the
   the PyNumero features that are considered stable.
